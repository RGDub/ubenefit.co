# ubenefit.co

Website for Universal Benefit Corporation, served with GitHub Pages at https://ubenefit.co.

- `index.html` — homepage (contact form in the Contact section)
- `connect/` — mobile "Let's connect" page the networking QR code opens (`/connect/?src=qr`)
- `thanks/` — confirmation page after a form submission
- `assets/` — favicon, QR code, contact card (.vcf)

Contact-form submissions post to a Google Form ("UBC Website Contact Form") whose responses land in the Google Sheet "UBC Website Contact Submissions".
